## Panoramica

Le transazioni ricorrenti generano automaticamente transazioni dovute in base a una pianificazione (giornaliera, settimanale, mensile, annuale).

## Funzionalità

- **Crea/modifica/elimina** regole ricorrenti con importo, categoria, frequenza e data di fine opzionale
- **Toggle Attiva/In Pausa** — Metti in pausa una regola ricorrente senza eliminarla
- **Rate prestiti** — Le regole ricorrenti possono contenere metadati del prestito (tasso, durata) per la suddivisione ammortizzata capitale/interessi
- **Generazione automatica** — Le transazioni dovute vengono generate al caricamento della dashboard tramite `generateDue`

## Supporto Rate Prestiti

Quando una transazione ricorrente ha `loanMeta`, ogni transazione generata viene automaticamente suddivisa in capitale e interessi in base al piano di ammortamento:

```typescript
interface LoanRecurringMeta {
  loanAmount: number
  annualRate: number
  termMonths: number
  startDate: string
}
```
