## Panoramica

I conti rappresentano le tue disponibilità finanziarie — conto corrente, risparmio, carte di credito, contanti, investimenti, prestiti e altri tipi di conto.

## Tipi di Conto

| Tipo | Classificazione | Esempi |
|---|---|---|
| `checking` | Attività | Conto corrente bancario |
| `savings` | Attività | Conto risparmio |
| `cash` | Attività | Contanti |
| `investment` | Attività | Conto titoli, fondi pensione |
| `other` | Attività | Attività varie |
| `credit_card` | Passività | Carte di credito |
| `loan` | Passività | Mutui, prestiti auto |

## Funzionalità

- **Crea/modifica/elimina** conti con nome, tipo, saldo e valuta
- **Pagina dettaglio conto** a `/accounts/[id]` con grafico andamento saldo e transazioni recenti
- **Calcolo patrimonio netto** — Attività meno passività
- **Drill-down dalla dashboard** — Clicca una scheda conto per vedere la pagina dettaglio

## Hook

```typescript
import { useAccounts, useCreateAccount, useUpdateAccount, useDeleteAccount } from "@/hooks/use-accounts"
```

Tutti gli hook di mutazione invalidano automaticamente le cache delle query `["accounts"]` e `["dashboard"]`.
