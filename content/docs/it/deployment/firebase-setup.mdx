Questa pagina riguarda il lato Firebase. I passaggi di distribuzione (App Hosting, segreti, regole, seed) sono in [docs/DEPLOYMENT.md](https://github.com/alfredo1996/alter-ego/blob/main/docs/DEPLOYMENT.md).

## Progetto

1. Crea un progetto nella [Console Firebase](https://console.firebase.google.com).
2. Abilita **Firestore Database**.
3. Abilita **Authentication** con il provider email/password.
4. Registra una **Web app** e copia i valori di configurazione.

## Regole di Sicurezza

Non scrivere regole tue. `firestore.rules` è generato da `firestore/base.rules` e contiene la validazione dei campi e la lista di accesso a un solo utente su cui l'app si basa.

```bash
pnpm rules:build
firebase deploy --only firestore:rules,firestore:indexes --project YOUR_PROJECT_ID
```

Per cambiare qualcosa modifica `firestore/base.rules`, mai il file generato.

## Chi Può Accedere

La registrazione è chiusa. Le regole ammettono un solo user id, `isAllowedUser` in `firestore/base.rules`, e lo stesso id compare in `apps/web/src/lib/owner-uid.ts`, che le route del server controllano. Crea il tuo utente nella console, sotto Authentication, inserisci il suo uid in entrambi i posti ed esegui `pnpm rules:build`.

## Categorie Predefinite

Inserisci le categorie predefinite nella collezione radice `categories` con l'Admin SDK (i client non possono scriverci):

```bash
FIREBASE_PROJECT_ID=YOUR_PROJECT_ID pnpm seed:firebase
```

## Emulatore

Per sviluppare su Firebase senza un progetto cloud:

```bash
pnpm emulator:start     # Auth, Firestore e interfaccia dell'emulatore, in Docker
pnpm dev:emulator       # l'app, con NEXT_PUBLIC_USE_EMULATOR=true, sulla porta 3003
```

`pnpm dev:emulator` imposta da solo le variabili dell'emulatore. L'emulatore avviato da `pnpm emulator:start` carica `firestore.rules` così com'è generato, quindi può scrivere solo l'uid autorizzato. Per una configurazione locale che conserva i dati e apre la lista di accesso usa invece `pnpm local:start`; vedi [docs/SELF-HOSTING.md](https://github.com/alfredo1996/alter-ego/blob/main/docs/SELF-HOSTING.md).
