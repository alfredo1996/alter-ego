## Panoramica

Alter Ego è un'app di finanza personale costruita con Next.js 16, TypeScript e Tailwind CSS v4: conti, transazioni, budget, obiettivi di risparmio, pagamenti ricorrenti e report. Un adapter backend ti permette di usarla con un mock in memoria o con Firebase senza cambiare il codice delle funzionalità. Un server MCP e un'API REST espongono gli stessi dati ad altri strumenti.

## Prerequisiti

- **Node.js** 24+ (vedi `.nvmrc`)
- **pnpm** 10+
- (Opzionale) **Docker**, per l'emulatore Firebase

## Avvio Rapido

```bash
git clone https://github.com/alfredo1996/alter-ego.git
cd alter-ego
pnpm install
pnpm dev
```

Apri [http://localhost:3000](http://localhost:3000) e accedi con qualsiasi email e password. Il backend mock tiene tutto in memoria, parte vuoto a parte le categorie predefinite e dimentica tutto al ricaricamento della pagina. Va bene per dare un'occhiata, non per un uso reale.

## Conservare i Dati

Per conservare i dati tra una sessione e l'altra, esegui l'app su un emulatore Firebase locale. Configurazione, client MCP e limiti di questo approccio sono in [docs/SELF-HOSTING.md](https://github.com/alfredo1996/alter-ego/blob/main/docs/SELF-HOSTING.md). Per eseguirla sul tuo progetto Firebase, vedi [Configurazione Firebase](/docs/deployment/firebase-setup).

## Variabili d'Ambiente

Copia `apps/web/.env.example` in `apps/web/.env.local`. Le variabili sono elencate nel README del repository. `NEXT_PUBLIC_BACKEND` vale `mock` (predefinito) o `firebase`; i valori Firebase servono solo per `firebase`.

## Script

| Comando | Descrizione |
|---|---|
| `pnpm dev` | Server di sviluppo con backend mock |
| `pnpm dev:emulator` | Server di sviluppo sull'emulatore locale |
| `pnpm build` | Build di produzione |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | Controllo dei tipi di ogni pacchetto |
| `pnpm test` | Vitest in modalità watch |
| `pnpm test --run` | Vitest una volta |
| `pnpm test:e2e` | Test end-to-end Playwright |

L'elenco completo è nel README.
