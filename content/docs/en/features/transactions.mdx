## Overview

Transactions are the core data entity — every income, expense, and transfer is a transaction linked to an account and optionally a category.

## Features

- **Create/edit/delete** with amount, date, description, category, type, and notes
- **CSV import** — Upload bank exports with auto-column mapping
- **Advanced filters** — By date range, amount range, category, account, type, tags, uncategorized, and note presence
- **URL-driven filters** — Dashboard drill-downs link to `/transactions?categoryId=X`
- **Bulk actions** — Select multiple transactions for batch operations
- **Swipeable rows** — Mobile gesture support for quick actions
- **Auto-categorization** — Rule-based category suggestion on description input

## Transaction Types

- `income` — Money coming in
- `expense` — Money going out
- `transfer` — Money moving between accounts
