## Overview

Savings goals let you define a target amount and deadline, then track contributions toward that goal.

## Features

- **Create/edit/delete** goals with name, target amount, current amount, and target date
- **Progress tracking** — Percentage complete, remaining amount, days remaining
- **Add funds** — Contribute to a goal from the goal card
- **Dashboard widget** — Top 3 active goals displayed on dashboard
- **Goal cards** — Visual progress bar with completion percentage

## Computed Fields

The `useSavingsGoalsWithProgress` hook enriches each goal with:

| Field | Description |
|---|---|
| `percentage` | `currentAmount / targetAmount * 100` |
| `remaining` | `targetAmount - currentAmount` |
| `daysRemaining` | Days until `targetDate` (0 if past) |
