## Overview

Alter Ego is a personal-finance app built with Next.js 16, TypeScript and Tailwind CSS v4: accounts, transactions, budgets, savings goals, recurring payments and reports. A backend adapter lets you run it against an in-memory mock or against Firebase without changing feature code. An MCP server and a REST API expose the same data to other tools.

## Prerequisites

- **Node.js** 24+ (see `.nvmrc`)
- **pnpm** 10+
- (Optional) **Docker**, for the Firebase emulator

## Quick Start

```bash
git clone https://github.com/alfredo1996/alter-ego.git
cd alter-ego
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) and sign in with any email and password. The mock backend keeps everything in memory, starts empty apart from the default categories, and forgets it all when you reload the page. It is good for a look around, not for real use.

## Keeping Your Data

To keep data between sessions, run the app against a local Firebase emulator. Setup, MCP client configuration and the limits of this approach are in [docs/SELF-HOSTING.md](https://github.com/alfredo1996/alter-ego/blob/main/docs/SELF-HOSTING.md). To run it on your own Firebase project, see [Firebase Setup](/docs/deployment/firebase-setup).

## Environment Variables

Copy `apps/web/.env.example` to `apps/web/.env.local`. The variables are listed in the repository README. `NEXT_PUBLIC_BACKEND` is `mock` (the default) or `firebase`; the Firebase values are needed only for `firebase`.

## Scripts

| Command | Description |
|---|---|
| `pnpm dev` | Dev server with the mock backend |
| `pnpm dev:emulator` | Dev server against the local emulator |
| `pnpm build` | Production build |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | Type-check every package |
| `pnpm test` | Vitest in watch mode |
| `pnpm test --run` | Vitest once |
| `pnpm test:e2e` | Playwright end-to-end tests |

The full list is in the README.
