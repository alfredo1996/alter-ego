## Adapter Pattern

Alter Ego uses an adapter pattern for all backend operations. Feature code never imports Firebase directly — everything goes through the `BackendAdapter` interface.

```typescript
// Always import from @/lib/backend
import { getBackend } from "@/lib/backend"

const backend = getBackend()
const accounts = await backend.db.getAccounts(userId)
```

## Interface

The adapter has three sub-interfaces:

```typescript
interface BackendAdapter {
  auth: AuthAdapter    // Sign in, sign out, onAuthStateChanged
  db: DatabaseAdapter  // All CRUD operations
  ai: AIAdapter        // AI features (optional)
}
```

### DatabaseAdapter

The `DatabaseAdapter` interface covers all data operations:

- **Accounts** — CRUD + balance updates
- **Transactions** — CRUD + filtering + CSV import
- **Categories** — Read (defaults + user custom)
- **Budgets** — CRUD
- **Savings Goals** — CRUD + add funds
- **Recurring Transactions** — CRUD + `generateDue`
- **Tags** — CRUD + transaction tagging
- **Categorization Rules** — CRUD + `applyCategorization`
- **Net Worth** — `takeSnapshot` + `getNetWorthHistory`
- **Dashboard / Reports** — Aggregated data queries

## Selecting a Backend

Set `NEXT_PUBLIC_BACKEND` in `apps/web/.env.local`:

| Value | Backend | Use Case |
|---|---|---|
| `mock` | In-memory store | Development, testing |
| `firebase` | Firestore + Firebase Auth | Production (Google Cloud) |
