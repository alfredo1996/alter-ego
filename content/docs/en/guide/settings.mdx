The Settings page lets you personalize Alter Ego and configure automation features. Changes take effect immediately.

## Profile

Edit your display name and email address. These are shown in the sidebar and used for your account identity.

- Tap the **Edit** button next to your profile information.
- Update your name or email.
- Tap **Save** to confirm.

## Theme

Choose how the app looks:

- **Light** — white background with dark text.
- **Dark** — dark background with light text.
- **System** — automatically matches your device's appearance setting.

The theme applies across all pages immediately.

## Currency & Locale

Set your preferred currency and locale for number formatting:

- **Currency** — determines the currency symbol used throughout the app (e.g., $, €, £).
- **Locale** — controls how numbers and dates are formatted (e.g., "1,234.56" vs. "1.234,56").

All amounts across the app — dashboard, transactions, reports, budgets, goals — use these settings.

## AI Mode

Control whether AI features are enabled:

- **Off** — no AI features. The app works entirely without AI.
- **Local** — AI features run on-device where possible.
- **Cloud** — AI features use cloud-based models for enhanced capabilities.

When AI mode is off, AI-related UI elements (like the chat button in the sidebar) are hidden. The app is fully functional without AI — it's always optional.

## Tags Management

Tags let you add extra labels to transactions beyond their category. Use them for cross-cutting concerns like "vacation", "tax-deductible", or "reimbursable".

### Creating a Tag

1. Scroll to the **Tags** section in Settings.
2. Tap **Add Tag**.
3. Enter a name and pick a color.
4. Tap **Save**.

### Deleting a Tag

Tap the delete button next to any tag. This removes the tag from all transactions that had it.

### Using Tags

When creating or editing a transaction, you can assign one or more tags. You can then filter the Transactions page by tag to see all related transactions across categories and accounts.

## Auto-Categorization Rules

Rules automatically assign a category to new transactions based on their description. This saves you from manually categorizing every transaction.

### Creating a Rule

1. Scroll to the **Categorization Rules** section in Settings.
2. Tap **Add Rule**.
3. Enter a **pattern** — the text to match in transaction descriptions (e.g., "Netflix", "Starbucks").
4. Select the **category** to assign when the pattern matches.
5. Tap **Save**.

The rule is active immediately. New transactions with a matching description will be auto-categorized.

### Enabling and Disabling Rules

Each rule has a toggle switch. Turn it off to temporarily disable a rule without deleting it. Turn it back on when you want it active again.

### How Matching Works

When you type a description in the transaction form, the app checks your active rules. If the description contains a rule's pattern (case-insensitive), the category is automatically filled in. You can always override the suggestion by selecting a different category.

## CSV Export

Tap the **Export** button in Settings to download all your transactions as a CSV file. The export includes:

- Date
- Description
- Amount
- Type (expense/income/transfer)
- Category
- Account name
- Notes

Use this to back up your data, share it with an accountant, or import it into a spreadsheet.

## Tips

- **Set currency first** — do this before entering any transactions so all amounts display correctly from the start.
- **Build rules as you go** — each time you categorize a transaction manually, consider whether it's a recurring merchant that deserves an auto-categorization rule.
- **Use tags sparingly** — tags are most useful when they represent a meaningful grouping you'll actually filter by. Too many tags can become noise.
- **Export periodically** — even though your data is stored in the app, having a CSV backup gives you peace of mind.
