Settings has five sections, listed on the side of the page: **Profile**, **Preferences**, **Categories & Tags**, **Data** and **Danger Zone**.

## Profile

Shows your display name and email. **Edit** lets you change both, then **Save Changes**.

## Preferences

- **Theme** — Light, Dark or System, which follows your device.
- **Currency** — used for totals and new accounts. Each account keeps its own currency.
- **Language and Format** — how numbers and dates are written.
- **AI Features** — Off, Local or Cloud. This setting is stored, but no AI provider is connected yet, so it changes nothing today. Everything in the app works without it.

## Categories & Tags

- **Categories** — **Open Categories** goes to the [Categories](/docs/guide/categories) page.
- **Tags** — labels that cut across categories, like a trip or a shared cost. Enter a name, pick a color and select **Add Tag**.
- **Auto-categorization Rules** — a **Pattern**, the **Category** to suggest, and an optional **Display as** name. Select **Add Rule**. When a description in the transaction form contains the pattern (ignoring case), the form suggests that category. Each rule has a switch to turn it off without deleting it.

## Data

- **Backup** — **Export All Data (JSON)** downloads one file with accounts, transactions, budgets, goals, tags and rules. A CSV of transactions is exported from the Transactions page instead.
- **API Keys** — **Generate New API Key** creates a key for scripts and the MCP server. The key is shown once, when you create it. Revoke a key to cut off anything using it. See [Self-hosting](https://github.com/alfredo1996/alter-ego/blob/main/docs/SELF-HOSTING.md) for how the key is used.
- **Connectors** — apps you signed in to with Alter Ego, such as Claude. **Disconnect All Connectors** signs all of them out; each asks you to approve again.

## Danger Zone

Each action asks you to confirm and none can be undone:

- **Delete All Transactions** — accounts, categories, budgets and rules stay.
- **Delete All Accounts & Transactions** (Start from Zero) — also removes recurring rules and balance history. Categories, tags, budgets and rules stay.
- **Reset Categories to Default**.

## Tips

- **Set the currency first**, before entering transactions.
- **Add a rule for each merchant you categorize by hand.**
- **Export now and then** for a backup you hold yourself.
