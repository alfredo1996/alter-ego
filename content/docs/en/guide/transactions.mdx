Transactions are the core of Alter Ego. Every time money moves — a purchase, a paycheck, a transfer between accounts — you record it as a transaction.

## Transaction Types

- **Expense** — money going out (groceries, rent, subscriptions).
- **Income** — money coming in (salary, freelance, refunds).
- **Transfer** — money moving between your own accounts (checking → savings).

## Creating a Transaction

1. Tap **New Transaction** in the header of the Dashboard, Accounts, or Transactions page, or the **+** in the top bar on a phone.
2. Choose the transaction type (expense, income, or transfer).
3. Fill in the amount, date, account, category, and an optional description and note.
4. Tap **Save**.

If you've set up auto-categorization rules, the category may be pre-filled based on the description you type.

## Quick Add on a Phone

On a phone, the **+** at the right end of the top bar adds a transaction from any personal page without navigating away. It opens the same transaction form dialog.

## Editing and Deleting

Tap any transaction in the list to open it. From there you can edit all fields or delete the transaction entirely. Deleting a transaction adjusts the associated account balance automatically.

## Swipe Gestures (Mobile)

On mobile devices, you can swipe transaction rows:

- **Swipe left** — reveals the delete action.
- **Swipe right** — reveals the edit action.

These gestures provide a faster way to manage transactions without opening each one.

## Filtering

The Transactions page provides powerful filters to narrow down your list:

- **Date range** — pick a start and/or end date.
- **Amount range** — set minimum and/or maximum amounts.
- **Category** — filter by one or more categories.
- **Account** — show only transactions from a specific account.
- **Type** — expense, income, or transfer.
- **Tags** — filter by assigned tags.
- **Uncategorized only** — show transactions that haven't been categorized yet.
- **Has note** — show only transactions with a note attached.

Filters are reflected in the URL, so you can bookmark or share a filtered view.

## CSV Import

You can import transactions from a CSV file in three steps:

1. **Upload** — select a CSV file from your device.
2. **Map columns** — match your CSV columns (date, amount, description, etc.) to Alter Ego fields. The importer auto-suggests mappings when it can.
3. **Review** — preview the parsed transactions, fix any issues, and confirm the import.

The importer handles various date formats and amount styles (negative numbers, parentheses, separate debit/credit columns).

## CSV Export

To export your transactions as a CSV file, go to **Settings** and tap the **Export** button. The file includes all transactions with their account names, categories, dates, amounts, and notes.

## Tips

- **Use the + button** — on a phone it's the fastest way to log a transaction the moment it happens.
- **Categorize everything** — the dashboard, budgets, and reports all depend on accurate categories. Set up auto-categorization rules in Settings to save time.
- **Tag for context** — tags let you add a second dimension beyond categories. For example, tag vacation expenses across multiple categories.
- **Import early** — if you're switching from another app, CSV import gets your historical data in quickly.
